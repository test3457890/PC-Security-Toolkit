PC SECURITY TOOLKIT: SCAN-ONLY SAFETY PREVIEW

Extract the complete ZIP before opening START HERE. Keep all Engine files together.
See Docs/Download and Run.md for the complete preview download and checksum steps.
No formatting or USB imaging is required for this scan-only folder.

Open START HERE for your OS, then confirm permission and choose Scan this PC.
Windows basic checks use current-user permissions. Do not elevate Guest Mode.
macOS/Linux require Python 3. Respect school/employer application controls.

No automatic toolkit report/log/config writes. Themes last for this page only.
Export JSON report explicitly downloads a file through the browser. Review it
before sharing. OS/browser/network records may remain.

Choose End session, confirm the launcher finishes, close the page and safely
eject the USB. Closing the tab alone does not stop the server.

THREE USB ROLES
1. Toolkit USB: manually open and scan. Preview implementation.
2. Secure Session USB: automatic activation on an owned, enrolled Windows host.
   Planned; no helper is installed or included in this preview.
3. Disposable Workspace USB: restart and boot a separate temporary live OS.
   Design only; no boot image included. No zero-trace or anonymity promise.

Legacy modification features are unavailable through the preview dashboard.
Standalone Profiles and the legacy Recovery launcher still modify Windows and
remain unaudited. They are outside Guest Mode. Snapshots cannot undo everything,
and restoring Windows defaults is different from restoring original settings.

Never disable OS protections, bypass device policies or clear audit logs to run
the toolkit. A successful scan does not prove the computer is secure.

Read README.md, Docs/Three USB Modes.md and Docs/Preview Validation.md for scope,
test evidence, unfinished features and privacy limitations.
