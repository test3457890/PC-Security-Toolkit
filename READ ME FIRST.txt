PC SECURITY TOOLKIT v3.1
========================

START
  Windows:  double-click "START HERE Windows.bat"   (keep the black window open)
  Mac:      double-click "START HERE Mac.command"
  Linux:    run  bash "START HERE Linux.sh"
  Broken?:  double-click "RECOVERY MODE Windows.bat" (works even if the dashboard won't open)

THEMES
  Click "Themes" at the top: Classic Midnight, Hacker Terminal, Cyberpunk Neon,
  Retro Amber, Deep Ocean, Daylight, High Contrast. Your pick is saved on the USB.

iPAD / iPHONE
  Basic mode (works now): plug it in with a USB cable, unlock it, tap "Trust",
  then open the "iPad, iPhone & Android" tab and click "Scan Connected Device".
  Bluetooth does not count as plugged in.

  Full mode (iPadOS version, passcode check, storage, battery, backup encryption,
  installed apps, and "Back up to this USB") needs two free extras:
    1. The "Apple Devices" app from the Microsoft Store (Windows driver for iPads).
    2. The libimobiledevice tools. ALREADY INCLUDED in Tools\libimobiledevice.
  These tools are not code-signed, so PCs with Windows "Smart App Control" turned on
  block them and the toolkit uses basic mode there. Leave Smart App Control on: turning
  it off can't be undone without reinstalling Windows.

FAMILY PLAN (parental controls)
  1. Give each child their own Windows account and keep it a STANDARD account.
  2. Open the "Family Plan" tab, set a parent PIN, tick the kids' accounts.
  3. Pick what to block, add extra sites and search words, pick sign-in hours.
  4. Click "Apply Family Plan". It keeps working after you unplug the USB.
  For a child's iPad, follow the Screen Time steps shown in the same tab.
  Forgot the PIN? Delete "Config\family settings.json" and set it up again.

RECOVERY MODE
  Before the toolkit changes anything, it saves a snapshot of this PC's settings in
  Backups\<PC name>\. In the "Recovery Mode" tab: Preview a snapshot, then Restore it.
  "Back to Windows defaults" undoes everything even without a snapshot.
  Also there: System Restore, Windows file repair, network reset, hosts reset,
  panic button (cut internet), Safe Mode and the Windows Recovery Environment.

REPORTS AND LOGS
  "Reports & Logs" tab: see what this PC is protected from (and what it isn't),
  save a full report to Reports\, and read the activity log in Logs\<PC name>\
  (every action, every script's full output, and any errors) if something goes wrong.

SAFETY
  The dashboard only works on this computer (127.0.0.1) and needs a new secret code
  every time it starts, so nobody on your network or the internet can get in through it.

DISCLAIMER
  No security tool can promise 100% protection. Nothing connected to the internet is
  ever completely safe. This toolkit's job is to make an attacker work harder and take
  longer, and to help you notice when something is wrong so you can act. Keep updates
  on, use strong passwords with 2-step sign-in, and keep backups. Use at your own risk.
